# 16:9 Ratio & Hybrid Platforming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework the game to a 16:9 aspect ratio at 512×288 viewport resolution (32×18 tiles per room at 16×16px) with hybrid platforming (15 curated 32×18 room templates + seed-based procedural micro-decorations).

**Architecture:** Centralize all dimension math in `src/config/GameConstants.ts` to eliminate hardcoded 320/240 values. Upgrade room matrices in `src/core/RoomTemplate.ts` to 32×18 with rich platforming archetypes, introduce a deterministic `src/core/RoomDecorator.ts` using Mulberry32 PRNG to inject non-blocking ledges and cover, and update `TilemapRenderer`, `CameraManager`, `HUD`, and `GameScene` to seamlessly support the expanded 2048×1152 world space.

**Tech Stack:** TypeScript (strict, `noEmit: true`), Phaser 3.90+ with Arcade Physics, Vite, Vitest (`happy-dom`).

## Global Constraints

- Native resolution: `512×288` pixels (`pixelArt: true`).
- Room dimensions: `32×18` tiles per room at `16×16` px per tile.
- World grid: 4×4 rooms = `128×72` tiles (`2048×1152` px physics world).
- Player speed: 120 px/s, Jump velocity: -340, Gravity: 600.
- Decoupled business logic: Pure math and algorithms must run headlessly in Vitest without WebGL/DOM canvas dependencies.
- Zero breaking changes to headless test execution (`npx vitest run`).

Create `src/core/RoomDecorator.ts`:
```typescript
import { SeededRNG } from './GridGenerator';

export function decorateRoomTiles(
  baseTiles: number[][],
  doors: { north: boolean; south: boolean; east: boolean; west: boolean },
  type: string | undefined,
  rng: SeededRNG
): number[][] {
  // Deep clone to prevent mutating template originals
  const matrix: number[][] = baseTiles.map((row) => [...row]);

  // Do not procedurally decorate START or BOSS rooms
  if (type === 'START' || type === 'BOSS') {
    return matrix;
  }

  // Eligible decorator zones: safe airspace away from portals
  // Zone A: cols 5 to 11, rows 7 to 13
  // Zone B: cols 20 to 26, rows 7 to 13
  const featureCount = rng.range(1, 2);

  for (let f = 0; f < featureCount; f++) {
    const zone = rng.next() < 0.5 ? 'A' : 'B';
    const startCol = zone === 'A' ? rng.range(5, 9) : rng.range(20, 24);
    const row = rng.choice([8, 10, 13]);
    const featureType = rng.choice(['LEDGE', 'STEP', 'PERCH']);

    if (featureType === 'LEDGE') {
      // 3-tile one-way platform (Tile 2)
      if (matrix[row][startCol] === 0 && matrix[row][startCol + 1] === 0 && matrix[row][startCol + 2] === 0) {
        matrix[row][startCol] = 2;
        matrix[row][startCol + 1] = 2;
        matrix[row][startCol + 2] = 2;
      }
    } else if (featureType === 'STEP') {
      // 2-tile solid step (Tile 1) at lower heights
      const stepRow = Math.min(row, 13);
      if (matrix[stepRow][startCol] === 0 && matrix[stepRow][startCol + 1] === 0) {
        matrix[stepRow][startCol] = 1;
        matrix[stepRow][startCol + 1] = 1;
      }
    } else if (featureType === 'PERCH') {
      // 1-tile ceiling mount (Tile 3) hanging from ceiling
      if (matrix[1][startCol] === 0 && matrix[2][startCol] === 0 && !doors.north) {
        matrix[1][startCol] = 3;
        matrix[2][startCol] = 3;
      }
    }
  }

  return matrix;
}
```
